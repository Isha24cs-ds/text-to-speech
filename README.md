# Text-to-SQL with Clarification Engine

A full-stack AI project that converts natural language questions into SQL queries and executes them on a database.

## Features

* Natural language to SQL using Gemini API
* Clarification engine for ambiguous queries
* SQLite database execution
* React frontend
* Node.js + Express backend
* SQL safety validation

## Tech Stack

* React + Vite
* Node.js + Express
* SQLite
* Google Gemini API

## Example Queries

* Show students with CGPA above 8
* List all CS-DS students
* Show top students

## Run Locally

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
